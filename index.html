End-to-End Dengue Forecasting in Southern Taiwan

Tools: Python, Pandas, Scikit-learn, XGBoost, Random Forest, LSTM, LSTM-Transformer, Time-series Forecasting, Streamlit, Supabase, Render, ArcGIS

Built an end-to-end forecasting system for weekly dengue cases in Kaohsiung, Tainan, and Pingtung using a 15-year (2010-2024) dataset that integrates dengue surveillance, climate, rainfall, and mosquito indices (BI/HI/CI). Implemented and compared tree-based and deep-learning models for one-week-ahead forecasts, with Random Forest and XGBoost achieving the most reliable performance on recent outbreaks. Delivered the solution as a cloud-hosted Streamlit dashboard backed by Supabase, plus an ArcGIS dashboard for spatial outbreak visualization, providing an early-warning tool to support public health decision-making.

Predicting Restaurant Ratings Using Yelp Metadata

Tools: Python, Scikit-learn, XGBoost, Random Forest, MLflow, Pandas, K-Prototypes

Designed and implemented a machine learning pipeline to predict restaurant success (≥4★ vs <4★) using structured metadata from 36,000+ Yelp businesses. Engineered 61 features and applied Logistic Regression, Elastic Net, Random Forest, and XGBoost with 5-fold cross-validation and MLflow experiment tracking. Optimized ensemble models, achieving 0.733 accuracy and 0.79 ROC-AUC with XGBoost. Conducted feature importance and clustering analyses to identify key drivers of customer satisfaction and uncover three restaurant archetypes (family-casual, mid-range social, quick-service), providing actionable insights for restaurant operations and marketing.
